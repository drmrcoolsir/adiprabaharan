Why B³ = A is a harder problem than it looks

July 2026 · 4 min read

The problem statement is short: given a matrix A, when does there exist a matrix B such that B³ = A? It reads like a warm-up exercise, the kind you'd skim past in a problem sheet. It isn't.

The first useful move is noticing that conjugation commutes with polynomial operations. If B = PDP⁻¹ for some diagonal D, then B³ = PD³P⁻¹ — so the whole question of finding a cube root reduces to finding a cube root of the eigenvalues, then reassembling the change of basis around it.

B = PDP⁻¹ ⟹ B³ = PD³P⁻¹ = A

That reframes the problem entirely: instead of hunting for B directly, you're exploiting a factorization you may already have from diagonalizing A. The interesting part isn't the algebra — it's noticing which structure to exploit before you start grinding through it.
